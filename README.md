# Сайт-портфолио

Демонстрационный сайт-портфолио: четыре страницы, формы с проверкой полей
и модальное окно добавления работы. Все данные на сайте вымышленные.

Проект переехал с gulp 3 + bower + jQuery 1.8 на **Vite + React + TypeScript**.

## Запуск

```bash
npm install
npm run dev
```

Сайт поднимется на <http://localhost:8000>.

Демо-доступ на странице входа: `demo` / `demo12345`.

## Команды

| Команда             | Что делает                                             |
| ------------------- | ------------------------------------------------------ |
| `npm run dev`       | Дев-сервер с горячей перезагрузкой и мок-бэкендом       |
| `npm run build`     | Проверка типов и продакшен-сборка в `dist/`             |
| `npm run preview`   | Локальный просмотр собранного `dist/` (мок тоже поднят) |
| `npm run typecheck` | Только проверка типов                                   |
| `npm run lint`      | ESLint: правила React Hooks и TypeScript                |

> TypeScript закреплён на 6.0: вышедший 7.0 пока не поддерживается
> `typescript-eslint` ([issue #10940][ts7]), и `npm run lint` с ним падает.
> Когда поддержку добавят, ограничение в `package.json` можно снять.

[ts7]: https://github.com/typescript-eslint/typescript-eslint/issues/10940

## Вход и сессия

Сайт закрыт целиком. Открыт единственный маршрут — `/login`; всё остальное
за `RequireAuth`, включая несуществующие адреса.

| Адрес       | Аноним                          |
| ----------- | ------------------------------- |
| `/`         | редирект на `/login`            |
| `/projects` | редирект на `/login`            |
| `/contact`  | редирект на `/login`            |
| `/login`    | форма входа                     |

- Сессия хранится в `sessionStorage` под ключом `portfolio.user`: переживает
  перезагрузку страницы и заканчивается вместе со вкладкой.
- Куда пользователь шёл, запоминается в состоянии перехода: после входа его
  возвращают туда же, а не на главную.
- В подвале — логин и кнопка «Выйти». Ссылки «Войти» там нет: на любой странице
  с подвалом пользователь уже вошёл, а у формы входа подвал пустой.
- Выход возвращает на `/login`, потому что текущая страница сразу перестаёт
  быть доступной.
- Вошедшего страница `/login` разворачивает обратно на сайт.
- Обращения к хранилищу обёрнуты в `try`: в приватном режиме сайт работает,
  просто не запоминает вход между перезагрузками.

Состояние живёт в [`src/auth/`](src/auth/): контекст и хук `useAuth` в
`context.ts`, провайдер в `AuthProvider.tsx`, охрана маршрутов в
`RequireAuth.tsx`.

> Это демонстрация потока входа, а не защита: пароль проверяет мок в браузерной
> вкладке, разметка страниц лежит в том же бандле, а `sessionStorage` правится
> из консоли за секунду. Настоящее ограничение доступа делается на сервере.

## Мок-бэкенд

Старые `login.php` и `add_project.php` заменены middleware внутри Vite —
отдельный процесс поднимать не нужно. Эндпоинты отвечают
`{ "ok": boolean, "message": string }`:

| Эндпоинт        | Успех, если                          |
| --------------- | ------------------------------------ |
| `/api/login`    | логин `demo`, пароль `demo12345`     |
| `/api/projects` | поле `name` не пустое                |
| `/api/contact`  | поле `email` не пустое               |

Логика живёт в [`mocks/api.ts`](mocks/api.ts) — там же задержка ответа,
чтобы было видно состояние «отправляется…».

## Что изменилось по сравнению со старой версией

- **Сборка.** gulp 3 (не запускается на современном Node) и bower → Vite.
- **Зависимости.** jQuery, qtip2, bPopup, placeholder.js, modernizr → ни одной
  сторонней библиотеки в рантайме, кроме React.
- **Страницы.** Четыре `.html` → четыре маршрута, общая шапка и сайдбар
  не перезагружаются при переходе.
- **CSS.** Вендорные префиксы, IE-хаки и `float` убраны; раскладка на grid и
  flex, цвета и размеры вынесены в кастомные свойства, вёрстка адаптивная.
- **Формы.** Один хук `useForm` вместо трёх копий одной и той же функции
  `_ajaxForm`; подсказки об ошибках — свои, без плагина.
- **Модальное окно.** Нативный `<dialog>` вместо bPopup: фокус-ловушка,
  закрытие по Esc и подложка достаются от браузера.
- **Адаптивность.** Старая вёрстка была прибита к `min-width: 970px`; теперь
  сайт работает и на телефоне.
- **Данные.** Личные данные, фотография и логотип заменены демонстрационными.
- **Вход.** В оригинале `login.js` получал ответ сервера и не делал с ним
  ничего — обе ветки `if/else` были пустыми. Теперь вход открывает сессию,
  без которой сайт не пускает дальше формы.
